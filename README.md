

# API Tijolinho

Sistema de gerenciamento de materiais de construção inspirado em um depósito familiar.

## Tecnologias

- Python
- Django
- SQLite
- Git
- GitHub

## Funcionalidades

- Cadastro de clientes
- Cadastro de produtos
- Cadastro de orçamentos
- Filtro de produtos por categoria

## Endpoints

GET /

Lista clientes

GET /produtos/

Lista produtos

GET /produtos/?categoria=Hidráulica

Filtra produtos por categoria

GET /categorias/

Lista categorias disponíveis
